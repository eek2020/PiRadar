# Reference Hardware

## Proven prototype

- Raspberry Pi 3 Model B v1.2
- Debian 13 (Trixie), 64-bit
- 5-inch 800×480 HDMI display
- XPT2046/ADS7846-compatible resistive touch controller
- Chromium 150 on Wayland

## Open hardware work

The exact display board, GPIO usage, power budget, touch-controller overlay and enclosure dimensions must be recorded before the first hardware alpha. Local ADS-B reception later requires a compatible RTL-SDR, 1090 MHz antenna and suitable placement.
