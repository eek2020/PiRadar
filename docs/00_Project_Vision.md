# PiRadar – Project Vision

## Goal

Build a polished Raspberry Pi based aircraft radar appliance that behaves like a commercial product rather than a hobby project.

## Principles

- Dedicated appliance
- Boots directly into the application
- No Linux desktop exposed
- Works without keyboard or mouse
- Uses an internet-fed aircraft source initially
- Has an upgrade path to an RTL-SDR local receiver
- Uses a maintainable, modular architecture

## Product definition

PiRadar is a single-purpose 800×480 touch appliance. On power-up it should move from a branded splash screen to a useful radar display without exposing operating-system or browser chrome. Loss of connectivity must produce a clear, recoverable state rather than a broken page.
