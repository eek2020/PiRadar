# Design Language

PiRadar's visual language is **quiet instrument**: functional, dark and precise, with a small amount of character in its typography and motion.

- Information density should serve quick recognition, not decoration.
- Motion communicates updates and selection; it should never distract.
- Colour always carries a second cue such as text, shape or position.
- Controls use plain language and generous touch targets.
- Branding stays subordinate to the airspace view after startup.
